# QuizZone 💡

A simple and responsive **quiz-themed web page** built using **HTML** and **CSS**.  
It features a clean navigation bar, section-based layout, and a visually appealing design — perfect for beginners learning front-end development.

---

## 🚀 Features

- Fully responsive navigation bar  
- Clean and modern UI  
- Section-based structure for easy content organization  
- Smooth hover effects for navigation links  
- Built using only **HTML** and **CSS** (no JavaScript)

---

## 🧱 Tech Stack

- **HTML5**
- **CSS3 (Flexbox, Keyframes, backdrop-filter, :has() selector)**
